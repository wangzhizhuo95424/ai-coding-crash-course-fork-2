项目地图与数据流

这是一个「迷你 Udemy」课程平台：学员浏览课程、看课时、做测验；教师管理课程；管理员管用户和分类。整份地图只回答一个问题 —— 想找某样东西，该打开哪个文件？

一次页面请求的完整链路

以打开课程详情 /courses/:slug 为例（官方课程「Fundamentals」章节会反复用到这条链路）：

01浏览器请求 URL → app/routes.ts:13 把它映射到 routes/courses.$slug.tsx
02app/root.tsx 的 Layout / Outlet 与 routes/layout.app.tsx 的布局 loader 先跑
03courses.$slug.tsx:54 的 loader 在服务端执行：取 slug、查课程、算进度、渲染 Markdown、解析国家定价
04查询下沉到 app/services/courseService.ts，通过 ~/db 拿到 db
05app/db/index.ts 懒加载打开 data.db（一个 Proxy，首次访问才真正连库）
06loader 返回普通对象 → 自动序列化为 loaderData prop → CourseDetail 组件渲染 HTML

React Router 官方 Data Loading 文档：SSR 下 loader 只在服务端跑，会从客户端 bundle 中移除，返回值自动序列化成 loaderData。react-router.config.ts 里 ssr: true 是开关。

四个新手易踩的坑

① 文档不一定对。 本地 README.md 写 React Router v7 + Ably，但 package.json 实际是 react-router 8.3.0 且没有 Ably 依赖。以代码为准，别以 README 为准 —— 这也是官方课程反复强调的工程态度。

② db:seed 会清库。 scripts/seed.ts:47-69 先 DROP TABLE 全部表再重建。本地有数据时别随手跑。

③ ./ +types/xxx 不是源码。 路由里的 import type { Route } from "./+types/..." 指向 .react-router/types/ 里的生成文件，必须先跑 typegen 才能 typecheck。

④ 星标 / 评分功能当前不存在。 它是课程练习的目标（course-star-ratings checkpoint），不是现有代码。别在仓库里白找。
