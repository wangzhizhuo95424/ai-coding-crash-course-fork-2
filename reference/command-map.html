npm 命令地图

本仓库 package.json 里每一条 scripts 都拆成了「真实命令 / 读哪个文件 / 改哪个文件 / 什么时候用」。看不懂某条命令时，先查这里，再去看源码。

读陌生命令的三步法

① 打开项目根目录的 package.json，在 scripts 里找到名字 → ② 顺着真实命令找到对应的配置（drizzle.config.ts / vite.config.ts / react-router.config.ts）→ ③ 再顺着配置找到被读写的源码或产物。npm 官方说明：npm run 会执行同名脚本，并把 node_modules/.bin 加入 PATH，所以脚本里能直接写 react-router、tsx 这类命令名。

最容易踩的坑

scripts/seed.ts:47-69 会先执行 DROP TABLE IF EXISTS 删掉全部表（包括迁移记录表），再重建并灌数据。本地 data.db 里已经有内容时，不要为了「初始化」重复跑 db:seed。

四条启动命令的正确顺序

01npm install —— 依赖到位（你的环境已完成）
02npm run db:migrate —— 按 drizzle/*.sql 在 data.db 里建表
03npm run db:seed —— 灌入课程 / 用户 / 课时等示例数据（会清库）
04npm run dev —— 启动 SSR 开发服务器，打开 http://localhost:5173

数据是怎么来到页面的

01app/db/schema.ts 定义 17 张表
02drizzle/*.sql 是建表剧本；scripts/seed.ts 灌示例数据 → data.db
03app/db/index.ts 打开 data.db，导出 db
04app/services/*.ts 用 db 查询；app/routes/*.tsx 的 loader 调 service
05app/routes.ts 把 URL 映射到路由模块 → 浏览器拿到 HTML
