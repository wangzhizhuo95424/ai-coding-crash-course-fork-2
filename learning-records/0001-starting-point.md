# 起点：只动手用过 npm/命令行，目标是跟官方课程练 AI 助手

用户自述：全栈新手，能读懂代码逻辑，只会简单 git 操作；实际动手过的技术只有 npm / 命令行（React、SQL、TypeScript 均未动手写过）。目标不是「学会全栈」，而是跟着 AI Coding Crash Course 六个章节，学会用 AI 助手探索、扩展、重构本仓库；每节课上限 10 分钟。

**Evidence**：首次课程对齐问卷（mission / prior / time 三问）的回答。

**Implications**：教学起点应落在 `package.json` 的 `scripts` 与终端命令上 —— 这是他唯一已有的动手经验，也是让 AI 助手探索陌生代码库时最自然的入口。不要预设组件、查询或类型系统的经验；每节课从「这个东西在本仓库的哪个文件」出发，而不是从概念定义出发。术语表和学习记录要等看到他真的用对了再更新。
